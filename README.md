# Ruby Learning Journey

## Two Paths, One Goal: Master Ruby!

### 📚 Chris Pine Book Exercises
Following "Learn to Program" by Chris Pine
- Each chapter gets its own folder
- Write programs as .rb files
- Run from terminal

### 🎸 Claude Ruby (Drum Machine Project)
Our musical approach to Ruby
- Daily lessons
- Building towards a drum machine/tracker
- Interactive learning with immediate feedback

### 🚀 Workflow
1. Open VS Code
2. Write your Ruby code
3. Save as .rb file
4. Open Terminal
5. Navigate to folder: `cd N:\TR_RUBY`
6. Run: `ruby filename.rb`

### 📁 Structure
- `/chris-pine-book/` - Book exercises by chapter
- `/claude-ruby/` - Our drum machine journey
- `/workflow-test/` - Test your setup here
- `/notes/` - Your learning notes
